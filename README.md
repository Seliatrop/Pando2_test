# PANDO2 Dashboard

Dashboard de visualisation des données de capteurs (CO2, Température, VOCT, Humidité).

## Démarrage rapide

### 1. Installer les dépendances

```bash
npm install
```

### 2. Lancer le serveur

```bash
npm start
```

### 3. Ouvrir dans le navigateur

Ouvrir [http://localhost:3000](http://localhost:3000)

## Fonctionnalités

-   **Filtres** : Sélectionner les salles et paramètres à afficher
-   **Graphiques** : Visualisation des données en temps réel avec Chart.js
-   **Responsive** : Interface adaptée à tous les écrans

## Technologies

-   Node.js + Express
-   Chart.js
-   HTML/CSS/JavaScript
